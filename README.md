# nand2teris

这里存放我 2026 年学习 Nand to Tetris 的课程项目。目录沿用课程编号，包含练习模板、示例程序和测试文件。

课程从 NAND 门开始，先搭建 Hack 计算机，再为它编写汇编器、VM 转换器、Jack 编译器和操作系统。

## 项目目录

| 目录 | 项目内容 |
| --- | --- |
| [`0`](0/) | 课程准备与提交练习 |
| [`1`](1/) | 布尔逻辑，包含基本逻辑门和多路复用器 |
| [`2`](2/) | 布尔算术，包含加法器和 ALU |
| [`3`](3/) | 时序逻辑，包含寄存器、程序计数器和 RAM |
| [`4`](4/) | Hack 汇编，练习乘法和屏幕填充 |
| [`5`](5/) | Hack 计算机，包含 CPU、内存和顶层连线 |
| [`6`](6/) | 汇编器，提供 `Add`、`Max`、`Rect` 和 `Pong` 等测试程序 |
| [`7`](7/) | VM 转换器 I，练习栈运算和内存访问 |
| [`8`](8/) | VM 转换器 II，练习程序控制和函数调用 |
| [`9`](9/) | Jack 编程，包含 `Square` 和 `Pong` 等示例 |
| [`10`](10/) | Jack 语法分析，提供源文件和 XML 对照文件 |
| [`11`](11/) | Jack 代码生成，提供编译器测试用的 Jack 程序 |
| [`12`](12/) | Jack 操作系统，包含 `Math`、`Memory`、`Screen` 等类的模板和测试 |
| [`13`](13/) | 后续项目提示 |
